##### 第一轮实验

目标是在保留原图精确判定的前提下，检验给不同关键点、不同方向分配索引半径，能否在相同标签条数上限下优于调优过的统一半径

| 实验要素 | 预先确定的设置 |
| --- | --- |
| 时间与资源 | 2026-11-25 00:08 启动，00:50 前停止启动本轮新测量（北京时间），在自有 CPU 上进行，最多 3 个单进程任务并行计入本轮，不使用付费服务 |
| 数据与真值 | Wiki-Vote、p2p-Gnutella31 的 SNAP 原图，独立的不限深单源 BFS 生成距离，验证集与测试集按源点隔离 |
| 查询 | 每张图测试一组混合阈值查询，$k\in\{2,4,6\}$，区分短路径、超过阈值的有限距离和不可达三类，按 $k$ 的分组共用同一索引 |
| 对照 | 单向限深 BFS、双向限深 BFS、固定版本 ESTI 作者代码，以及本框架的统一 $h$ |
| 唯一候选 | 按图结构而非查询答案给各关键点的入、出方向分配完整 BFS 层，最大半径 6；对照组在验证集比较所有可行的统一 $h=0,\ldots,6$ |
| 索引预算 | 每张图由同一规则选 12 个关键点，标签上限为 $4\lvert V\rvert$ 条，根标签也计数；上限相同，实际条数、分配字节和构建开销分别测量 |
| 验收 | 对照与候选逐条对照真值，报告错误数。首先看是否完全正确，再看测试集平均延迟、P95、扫描边数、证真／证伪比例、构建与选择代价 |
| 判读 | 两图均优于统一半径且多数重复方向一致才考虑扩大验证，单图获益只做结构诊断；若直接双向 BFS 更快，报告差距。一次小规模负载不能证明普遍性能或新颖性 |

按验证集三个重复轮次的平均查询延迟中位数选择统一半径，同分优先较浅；测试集五轮轮换方法顺序，每条请求单线程。ESTI 的原生实现单独核对答案，跨语言时间单列。先完成这一轮，再决定是否引入训练负载、更多图或另一种半径策略
